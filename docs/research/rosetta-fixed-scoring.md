# Atom-fixed Rosetta scoring of retained completion candidates

Status: **private, retrospective scoring pilot**, not a new completion backend,
steric gate, public capability or independent scientific qualification. Follows
the [Rosetta mechanism study](rosetta-repack-mechanism.md) and
[48-mask reconstruction comparison](protein-completion-unfiltered.md).

Continuation: the [predeclared three-system follow-up](rosetta-scoring-followup.md)
now retains an explicit CONECT-order protocol amendment and all barstar source
refusals. The unchanged rule improves one additional lysozyme mask; this does not
convert the retrospective pilot below into prospective evidence or broad validation.

## Question and frozen protocol

Can Rosetta evaluate already generated candidates **without repacking or moving
any observed heavy atom**, and improve selection within the existing feasible
pool? No new coordinates are generated by our completion kernel in this study.

`scripts/research_rosetta_fixed_scoring.py plan` reuses every declared mask of the
earlier 48-case plan. Sixteen shared admission refusals remain refused. For the
32 admitted cases, it materializes **all 64 retained own attempts**, 32 retained
seeded-template proposals and 32 native controls: **128 scoring inputs**. Rejected
attempts remain diagnostic inputs, never candidates rescued by a favorable score.

Inputs and old source/common audits are frozen before scoring. Each input is the
original source with only requested atoms inserted, at **PDB-rounded coordinates**.
No new rotamer generation, refinement, reflection or observation restoration.

Selection policy, fixed before scores:

1. Only own attempts passing **both** the unchanged source audit and unchanged
   common raw/rounded/stereo gate are eligible.
2. All eligible attempts must have valid, comparable scores. A missing feasible
   score blocks selection; do not discard that candidate and pick another.
3. Minimize total `ref2015` score, with original attempt index as tie-break.
4. Commit selection before importing native controls. Reference RMSD is calculated
   subsequently by a separate saved-artifact summarizer, never used for ranking.

The old and new selectors therefore have the **same feasible pool**, not the same
selection criterion. Old feasibility thresholds and historical results are intact.

## What scoring is allowed to do

Installed PyRosetta remains 2026.06 / Rosetta
`1a56185c2592611dec4c9c75ddc9468cd2227c1f`. A single-threaded process uses seed 7,
explicit `ref2015`, import packing **off**, and H optimization **off**. Each fully
specified heavy candidate is independently re-imported so H coordinates are built
for that candidate, rather than carried over from an incompatible conformation.
This is full-pose scoring, not an isolated atom-pair energy or Cartesian minimizer.

An input is scoreable only if:

- Every input physical heavy atom, including generated atoms, survives with
  **exactly equal coordinates and identity**, not merely within a restraint or
  1e-7 Å tolerance. Original source records remain byte-identical in scoring inputs.
- Imported inter-residue heavy bonds equal the source-derived external links,
  and target intra-residue heavy bonds equal the canonical target graph.
- Additional physical heavy atoms are limited to explicitly reported terminal
  OXT on an upper terminus without an outgoing declared C–N link.
- Typed virtual atoms are separately retained as scorer-owned pseudoatoms; never
  exempt an input atom or an arbitrary physical atom just because its name is NV.
- Scoring itself moves no physical heavy atom. Residue types/atom inventories and
  external/target topology fingerprints remain comparable within each case.

The independent summarizer additionally verifies unchanged source records, score
term sums, and identical scorer-owned terminal OXT, virtual coordinates and
**non-target H coordinates** across each case's candidates/controls. These checks
passed. Target H coordinates may vary with the generated heavy conformation.

Topology coverage is intentionally bounded: external links and target internal
connectivity are independently checked, **not every context internal bond order**.
Hydrogens/default Rosetta protonation were not optimized or independently
qualified. This does not reproduce legacy PROPKA/Reduce protonation or establish
calibrated absolute energies; Rosetta score units are not claimed as kcal/mol.

## Virtual-atom discovery and retained blockers

The first executable inventory protocol blocked **all 128 inputs before scoring**:
Rosetta adds a virtual `NV` to each PRO. It is included in Rosetta's heavy-atom
index range but is not a new physical nitrogen. Runtime atom typing
supports distinguishing it with `AtomType::is_virtual()`.

A **separate version-2 scoring plan** therefore inventories physical and typed
virtual atoms separately. No physical-coordinate allowance, atom-name whitelist,
bond filter or old geometry threshold was relaxed. Original observations could
not disappear through virtual classification: the physical-input audit would fail.
All old snapshots, zero-score outcomes and executed harness bytes remain retained.
A prior JSON mapping-proxy serialization failure and a missing-PYTHONPATH invocation
are also retained as setup/protocol blockers, not scientific proposal failures.

## Executed results

[Portable independent evidence](rosetta-fixed-scoring-evidence.json) and local
`tmp/pdbfixer-research/rosetta-fixed-{plan-03,run-04}/` retain the final protocol.
All **128/128 inputs scored** and independently passed physical/topology snapshot
readback. Source bytes were preserved in each scoring input; imported physical
heavy coordinates stayed exact. No within-case context-coordinate comparison
blockers were found.

| Denominator | Count |
|---|---:|
| Originally declared masks | 48 |
| Shared source admission refusals, unchanged | 16 |
| Admitted cases | 32 |
| Cases with zero old-gate-feasible own candidates | 1 |
| Cases with one feasible own candidate | 22 |
| Cases with two / three feasible own candidates | 2 / 7 |
| Cases selected by either policy | 31 |
| Cases where scoring changed selection | 3 |

Only **nine cases** offered a genuine choice. Singleton solvers supply one attempt;
score cannot improve their sampling. VAL39 CG1 in 1TIM remains rejected despite
being scored: the native 1–4 steric-gate limitation has not been bypassed.

All three changed selections improved post-selection exact-name RMSD:

| Mask | Old selector | Score selector |
|---|---:|---:|
| 1EMV THR11, OG1/CG2 missing | 2.483 Å | 0.167 Å |
| 1EMV THR11, CB/OG1/CG2 missing | 2.000 Å | 0.183 Å |
| 1EMV THR20, CB/OG1/CG2 missing | 1.977 Å | 0.036 Å |

These are **three correlated masks on two residues of one structure**, not three
independent proteins or randomized/blind trials. 1EMV is also homologous to the
previously studied 1FR2. The previous observations and results were known when this
new scoring policy was chosen; no prospective accuracy claim is justified.

Matched all-own-feasible subsets, **rounded** generated-coordinate medians:

| Class | Same-case denominator | Old selector | Score selector |
|---|---:|---:|---:|
| Paired / whole sidechain | 16 | 0.221 Å | 0.176 Å |
| Anchored singleton | 15 | 0.041 Å | 0.041 Å |

These are not the earlier own/template **mutually passing** n=8/n=9 subsets or raw
coordinate medians. No template or native proposal participates in own selection.
The poor historical 1A3N VAL1 whole-sidechain result is outside this cohort and
remains unresolved. Scoring has not increased reconstruction coverage.

## Topology diagnostics do not remove steric findings

`scripts/rosetta_fixed_contract.py` adds a descriptive shortest-path label to the
**unchanged -0.6 Å VDW clearance findings**, excluding only the old bonded and
angle-connected pairs. Across the 128 rounded inputs, all **34 old clash instances**
remain present: ten have a known three-bond (1–4) path; 24 have no short path in the
partial graph. These counts repeat proposals/masks and are not unique defect sites.

The graph contains canonical target bonds and declared external links, not a full
context chemical graph. Therefore "no short path" means **unresolved**, not proven
nonbonded or necessarily intermolecular. Genuine new–new collisions remain checked.

Three native-control failures still expose the same 1TIM VAL39 CG1–C contact.
But known 1–4 findings also include a template THR11 OG1–N contact at **1.989 Å**.
Path classification alone cannot establish a chemically acceptable contact: simply
exempting every 1–4 pair would hide other problems. No replacement gate is enabled.

## Reproduction and verification

Normal scientific environment plans; the existing PyRosetta environment scores;
the normal environment independently audits/report-scores saved artifacts:

```bash
PYTHONPATH=src:. python scripts/research_rosetta_fixed_scoring.py plan --comparison docs/research/protein-completion-unfiltered-evidence.json --output tmp/pdbfixer-research/new-fixed-plan
# Use the existing licensed PyRosetta interpreter here. No installation required.
PYTHONPATH=. python scripts/research_rosetta_fixed_scoring.py run --plan tmp/pdbfixer-research/new-fixed-plan --output tmp/pdbfixer-research/new-fixed-run
PYTHONPATH=src:. python scripts/summarize_rosetta_fixed_scoring.py --plan tmp/pdbfixer-research/new-fixed-plan --run tmp/pdbfixer-research/new-fixed-run --output tmp/pdbfixer-research/new-fixed-summary.json
```

Use exclusive new destinations. Planning requires the retained earlier comparison
artifacts, not only its portable aggregate. Frozen input/implementation hashes are
checked. Scoring output snapshots include physical heavy atoms, H coordinates,
virtual types/coordinates, residue-type inventories, topology and score terms.
Saved-result replay is not an independent reimplementation of Rosetta energy.

**575 focused tests passed in 25.90 s**, including exact-coordinate/record checks,
chain/insertion-code identity, topology mismatch rejection, typed-virtual inventory,
partial-graph labels, retained new–new clashes, stable ties and missing-score
fail-closed selection. Targeted Ruff passed. This is not the full repository suite.
Seventeen-file private-package mypy and agent maps also passed. Independent
readback of this pilot, the prior 16-cell Rosetta study and all 32 native-reference
audits is byte-identical; prior 48-case and original/mixed bundle checks still pass.

Next: challenge the frozen scoring policy on prospectively selected different
families/masks; then test joint fixed-atom combinations with exact small-case search.
Richer feasible sampling and independently calibrated chemistry-aware sterics
remain separate problems. No production integration, PyRosetta dependency, library
export, licensing clearance, downstream refinement or broader qualification.
