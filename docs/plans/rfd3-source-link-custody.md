### B. Retain raw native evidence before source restoration

Keep raw native arrays/files, axes and effective configuration before any fit,

The raw fixation tolerance and transport precision must be declared before a

### C. Materialize missing atoms without overwriting observations

Reuse [`materialize_candidate_pdb`](../../src/dvbfixer/model/diffusion/pdb_materialize.py)
and [`reconcile_pdb_metadata`](../../src/dvbfixer/model/diffusion/pdb_metadata.py),
with a private adapter and independent postconditions rather than copied PDB logic.

candidate axis contains fixed atoms. Its name alone does not guarantee immutable

annotations; record its changes, but never hide a lost required link in that list.

### D. Independently audit the final bytes

A reader independent of the adapter worker must resolve final atom identities
and links from final bytes and compare them with the original source ledger.
Checking that an SSBOND line exists or that a report says “18” is insufficient.

Require exact source observation records and original declared endpoint pairs,
zero added/lost required explicit links, correct endpoint residue/atom names and
serial references, and unchanged source SG coordinates/distances. Retain link
provenance/operators; refuse unresolved or changed endpoints. A close SG pair
without its required annotation fails custody; annotation with wrong geometry
also fails. Do not replace chemical validation with a distance-only bond detector.

Separately validate complete requested sequence/inventory, all peptide junctions,
existing versioned clash/bond/angle/torsion criteria and global L-chirality.
Evaluate both raw-aligned and source-preserved results: inserting source records
can create junction clashes even if a moving native scaffold looked clean.
Any generated-only repair needs a separate declared budget/policy and new audits;
none is automatically enabled here. Never reflect an observed residue to force L.

Retain source, raw, aligned, materialized and any later repaired findings as
distinct stages. Explicit-link custody is not an all-ring/threading, force-field,
protonation or downstream simulation guarantee.
