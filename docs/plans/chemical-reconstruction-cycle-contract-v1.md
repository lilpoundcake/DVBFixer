## Separate role, not an existing geometry parent

Add a separately tagged immutable CycleConstructionProblem, NOT GeometryPlan,
Candidate, ProjectionPlan/Result, ConformerSearchResult, ChemicalState or a request
subclass with generated conditioning. Inputs are ONLY the original source request,
caller-declared additional constraints and three explicit observed frame identities.
There is NO seed/candidate/reference/score/baseline input field. Do not silently
accept rejected coordinates as an initializer, require an old geometry pass to
plan chemistry, or weaken the existing projector's passing-parent gate.

The problem binds complete source request/observations/graph, extra constraints,
effective constraint-request digest, variable order, observed frame and frozen
policy. New constraint-request provenance uses its OWN cycle_construction tag;
do NOT reuse append_projection_constraints or its metric_projection namespace.
Keep source observations/state/links/pH/ownership and original constraint prefix
exact. A PreparedContextRequest keeps its existing conservative context proof;
fractional opaque context remains unowned/unconstrained/unlinked. Reject nested
conditioning/projection/cycle-origin requests; never relabel generated conditioning
as measured source. Full source admission is independently required outside DTOs.

All execution/geometry/source-coverage/MD-readiness properties remain False. Strict
known-DTO JSON may register the new standalone DTOs, NOT extend old GeometryPlan
variants or Strategy values. A transport roundtrip is not scientific qualification.
